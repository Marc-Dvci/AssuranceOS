## What this repository contains, and what it deliberately does not

Everything the platform reads in the demonstration is synthetic and lives in this
repository, so any result can be reproduced byte for byte.

This repository contains **no** model weights, customer data, personal data,
licensed standards text, or cloud credentials. Asteria Systems SAS is a fictional
company that exists only for demonstration; its domains use the reserved
`.invalid` suffix and its entire corpus is generated deterministically by
`scripts/build_demo_corpus.py`.

Third-party dependencies retain their own licenses, resolved in `uv.lock`.
